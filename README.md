# Exercícios de AED1 em C

Soluções de exercícios de Algoritmos e Estruturas de Dados I. Os arquivos numerados na raiz são programas independentes; `Testes/teste_filas.c` reúne um teste de filas.

## Estrutura

- Arquivos `.c`: exercícios independentes (ou o programa indicado acima).
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/AED1_1276216.git
cd AED1_1276216
gcc 1068.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações

Escolha um arquivo por vez: cada exercício pode ter sua própria função `main`.
